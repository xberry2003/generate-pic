# 图片标题字段

批量工作台在“原始描述”后新增可选的“标题”列（最多 200 字）。标题不参与图像生成提示词。手动标题去掉首尾空白后优先作为图片库显示标题；标题留空或仅包含空格时，回退为原始描述。

- 工作台行新增 `title`，随 `/api/workspace/rows` 保存和恢复。
- `/api/generate`、`/api/generate/draft`、`/api/generate/upload` 接收可选 `title`。
- `/api/images/{id}/metadata` 接收可选 `title`：省略时保留已有标题，空字符串时清空自定义标题。
- 图片响应的 `title` 是最终显示标题，`customTitle` 是独立保存的手动标题；`prompt` 和 `originalPrompt` 保留原始描述。
- 已上传图片可以在工作台修改标题并自动保存，无需重新生成。
- 管理员修改名称写入独立标题字段，不再覆盖原始描述。
- 图片搜索支持标题；工作台图片库和独立图片库使用同一后端标题。
- CSV 模板包含 `prompt,标题`，兼容旧单列 CSV，支持 `title` 英文字段名及有表头时的列顺序调整。

数据库 `images` 和 `workspace_rows` 新增可空的 `VARCHAR(200)` 标题列。启动时沿用项目已有 SQLite 增量升级机制，仅补列，不改写旧记录。
