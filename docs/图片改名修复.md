# 图片改名修复（2026-10-22）

原因：COS-only 图片返回 `cos-<index>`，旧改名接口只接收数字 ID；FastAPI 返回 422 后，前端又把 `detail` 对象数组直接交给 React 渲染，触发错误。

改名请求现在接受字符串 ID。数字 ID 继续更新原记录；临时 COS ID 必须携带 Body 字段 `cosKey`，后端校验目录范围和图片存在性，查询已有 metadata 或补建记录，再写入独立 `title` 字段。响应返回稳定的数字 ID。只改显示标题，不移动 COS 文件，不改变原始描述；管理员权限保留。

前端发送真实 key，成功时使用后端返回的新 ID 更新卡片。错误详情统一转为文字并记录控制台日志。

## 验证

- `backend/tests/test_image_title.py`：7 项标题与旧版兼容测试。
- `backend/tests/test_cos_rename.py`：7 项 COS-only 创建、重复请求、数字 ID、非法路径、对象不存在、存储失败与权限测试。
- 独立图片库和工作台 iframe 均在浏览器中验证了成功及 422 分支，无 React 错误；浏览器写请求被拦截，未改真实图片名称。
